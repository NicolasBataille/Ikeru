# Notes de review — Ikeru (app d'apprentissage du japonais)

Ce dossier contient les notes d'une **review indépendante et intransigeante**
d'Ikeru, application iOS d'apprentissage du japonais **non encore sortie**.

La review est menée par un expert en didactique du japonais (SLA — Second
Language Acquisition — et psycholinguistique de l'acquisition du japonais).
Elle se déroule **uniquement** via :

- test sur **simulateur iOS** (parcours utilisateur réel, aucun raccourci),
- **échanges directs avec le développeur** (présentation, questions,
  clarifications).

**Le code source n'est à aucun moment lu ou consulté** dans le cadre de cette
review — l'évaluation porte sur l'expérience et le comportement observables
de l'application, pas sur son implémentation.
