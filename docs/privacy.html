Politique de confidentialité — Ikeru

Dernière mise à jour : 14 août 2026

Résumé

Ikeru est une application personnelle d'apprentissage du japonais. Toutes les données d'apprentissage (progression, deck de cartes, statistiques) sont stockées localement sur votre appareil. Il n'y a pas de tracking, pas d'analytics et pas de publicité. Un compte n'est jamais requis : par défaut, la sauvegarde cloud optionnelle utilise un identifiant anonyme, sans e-mail ni mot de passe. Vous pouvez choisir de vous connecter avec Apple pour retrouver votre progression sur un autre appareil ; dans ce cas seulement, un compte est créé et une adresse e-mail (la vôtre, ou une adresse de relais si vous l'avez masquée avec Apple) est stockée par notre fournisseur d'authentification. Trois fonctionnalités optionnelles au total — décrites ci-dessous — peuvent envoyer des données hors de l'appareil, uniquement si vous les activez.

Données collectées

Ikeru stocke localement, sur votre iPhone :

  • Votre progression d'apprentissage (cartes, niveaux, statistiques)
  • Votre prénom (utilisé pour personnaliser l'écran d'accueil)
  • Les notes et préférences que vous configurez dans l'app

Par défaut, ces données ne quittent pas votre appareil. Trois fonctionnalités optionnelles peuvent envoyer des données hors de l'appareil : les fonctions d'IA (si vous configurez une clé API), la reconnaissance vocale (selon l'appareil) et la sauvegarde cloud (si vous l'activez dans Réglages). Une sauvegarde iCloud distincte est également prévue à terme, mais n'est pas encore activée dans cette build : voir la section dédiée ci-dessous.

Fonctions d'IA optionnelles

Les modes conversation et génération de moyens mnémotechniques peuvent utiliser des services d'IA tiers, uniquement si vous configurez vous-même une clé API dans les réglages de l'app. Sans clé configurée, aucune donnée n'est envoyée à ces services.

  • Fournisseurs pris en charge : Google Gemini, Groq, Cerebras, OpenRouter, GitHub Models, et éventuellement Anthropic Claude si vous ajoutez une clé dédiée.
  • Ce qui est envoyé : uniquement le texte de vos conversations ou les termes pour lesquels un moyen mnémotechnique est généré — jamais votre profil complet, votre prénom ni votre historique de révision.
  • Vos clés API sont stockées dans le Trousseau (Keychain) iOS et ne sont jamais transmises ailleurs qu'au fournisseur concerné.
  • Le texte envoyé est traité selon la politique de confidentialité du fournisseur que vous avez choisi.
  • Option avancée : vous pouvez pointer l'app vers votre propre serveur d'IA auto-hébergé sur votre réseau local ; dans ce cas, le texte est envoyé à ce serveur qui vous appartient.

Reconnaissance vocale

Pour les exercices de prononciation, Ikeru utilise la reconnaissance vocale d'Apple. Lorsque votre appareil prend en charge la reconnaissance sur l'appareil, l'app l'exige et l'audio ne quitte pas votre iPhone. Si la reconnaissance sur l'appareil n'est pas disponible, l'audio est traité par les serveurs de reconnaissance vocale d'Apple, conformément à la politique de confidentialité d'Apple.

Sauvegarde cloud (optionnelle)

Ikeru propose une sauvegarde cloud de vos données d'apprentissage, désactivée par défaut et activable dans Réglages. Elle est hébergée sur Supabase, en région Union européenne.

  • Compte optionnel : quand vous activez cette fonctionnalité, l'app crée par défaut un identifiant anonyme aléatoire, lié à cet appareil, stocké dans le Trousseau (Keychain) iOS. Il n'y a alors ni e-mail, ni nom de connexion, ni mot de passe, et cet identifiant ne permet pas de vous identifier personnellement.
  • Connexion avec Apple (optionnelle) : vous pouvez, si vous le souhaitez, rattacher cet identifiant anonyme à votre identifiant Apple via « Se connecter avec Apple », sans rien perdre de ce qui a déjà été sauvegardé. Un compte est alors créé, et Apple transmet à notre fournisseur d'authentification (Supabase) l'adresse e-mail associée à votre identifiant Apple — potentiellement une adresse de relais privée si vous avez choisi de masquer votre e-mail auprès d'Apple. Ikeru elle-même ne lit, n'affiche ni ne stocke cette adresse ; elle est conservée par Supabase, rattachée à votre compte, au même titre que le reste de vos données. L'intérêt : retrouver votre progression sur un autre appareil en vous connectant avec le même identifiant Apple.
  • Ce qui est envoyé : votre progression d'apprentissage, vos cartes et leur état de mémorisation, votre historique de révision, le vocabulaire que vous avez enregistré, vos résultats d'exercices, le prénom que vous avez saisi dans le profil, et vos préférences d'apprentissage (objectifs quotidiens, taux de rétention visé, et si vous les avez activés, l'heure de votre rappel de révision et le jour et l'heure de votre bilan hebdomadaire). Si vous vous connectez avec Apple, s'y ajoute l'adresse e-mail décrite ci-dessus.
  • Ce qui n'est jamais envoyé : vos conversations avec Sakura (elles restent sur l'appareil), les phrases d'exemple dans lesquelles vous avez rencontré un mot, vos clés API, et vos enregistrements vocaux.
  • Restauration multi-appareils : sans connexion Apple, la sauvegarde reste à sens unique par appareil — chaque appareil ayant son propre identifiant anonyme, il n'y a pas de restauration automatique sur un nouvel appareil. En vous connectant avec Apple sur plusieurs appareils avec le même identifiant Apple, ces appareils partagent le même compte et votre progression peut être récupérée et fusionnée sur le nouvel appareil.
  • Suppression : vous pouvez à tout moment supprimer l'intégralité de vos données du serveur depuis Réglages, ce qui efface aussi l'identifiant anonyme et, si vous vous êtes connecté avec Apple, le compte et l'identité Apple associée — il ne reste alors plus aucune trace de vous côté serveur.

Sauvegarde iCloud (pas encore disponible)

Il s'agit d'une fonctionnalité distincte de la sauvegarde cloud Supabase décrite ci-dessus. Ikeru contient l'infrastructure d'une future sauvegarde iCloud optionnelle, mais elle est désactivée dans la version actuelle le temps que le compte développeur Apple soit pleinement activé : il n'y a aujourd'hui aucun réglage pour l'activer dans l'app, et aucune donnée n'est envoyée à iCloud. Quand cette fonctionnalité sera livrée, vos données d'apprentissage seraient stockées dans la base de données privée CloudKit de votre compte iCloud personnel, chiffrées en transit et au repos, mais pas chiffrées de bout en bout par défaut : Apple détiendrait les clés de chiffrement, sauf si vous avez activé la Protection avancée des données sur votre compte iCloud. Le développeur d'Ikeru n'aurait en aucun cas accès à ces données. Cette section sera mise à jour dès que la fonctionnalité sera active.

Services tiers

Ikeru n'utilise aucun service tiers de tracking, d'analytics ou de publicité. En dehors des fonctions optionnelles décrites ci-dessus, les seules informations qu'Apple collecte sont celles décrites dans la politique de confidentialité d'Apple dans le cadre du fonctionnement de TestFlight (rapports de crash, statistiques d'utilisation anonymes destinées au développeur).

Permissions demandées

  • Notifications (optionnel) : pour le rappel quotidien du « Terme du jour », les rappels de révision et le bilan hebdomadaire
  • Microphone (optionnel) : pour les exercices de prononciation
  • Reconnaissance vocale (optionnel) : pour transcrire votre voix pendant les exercices de prononciation

Toutes les permissions peuvent être révoquées à tout moment depuis les Réglages iOS.

Vos droits

Pour effacer toutes les données stockées localement par Ikeru : désinstallez simplement l'application depuis votre iPhone. Si vous avez activé la sauvegarde cloud, vous pouvez à tout moment supprimer l'intégralité de vos données du serveur depuis Réglages, ce qui efface aussi l'identifiant anonyme et, le cas échéant, le compte et l'identité Apple associée. Pour la portabilité de vos données, un export local est disponible dans l'app. Pour les données envoyées à un fournisseur d'IA que vous avez configuré, référez-vous à la politique de confidentialité de ce fournisseur.

Privacy Policy — Ikeru

Last updated: August 14, 2026

Summary

Ikeru is a personal Japanese-learning app. All learning data (progress, card deck, statistics) is stored locally on your device. There is no tracking, no analytics and no ads. An account is never required: by default, the optional cloud backup uses an anonymous identifier, with no email and no password. You can choose to sign in with Apple to get your progress back on another device; only then is an account created, and an email address (yours, or a relay address if you chose to hide it) is stored by our authentication provider. Three optional features in total — described below — can send data off the device, and only if you enable them.

Data collected

Ikeru stores locally, on your iPhone:

  • Your learning progress (cards, levels, statistics)
  • Your first name (used to personalise the home screen)
  • Notes and preferences you configure inside the app

By default, this data does not leave your device. Three optional features can send data off the device: the AI features (if you configure an API key), speech recognition (depending on your device), and cloud backup (if you turn it on in Settings). A separate iCloud backup feature is also planned, but not yet enabled in this build — see the dedicated section below.

Optional AI features

The conversation and mnemonic-generation features can use third-party AI services, but only if you configure an API key yourself in the app's settings. Without a configured key, no data is sent to these services.

  • Supported providers: Google Gemini, Groq, Cerebras, OpenRouter, GitHub Models, and optionally Anthropic Claude if you add a dedicated key.
  • What is sent: only the text of your conversations or the terms a mnemonic is being generated for — never your full profile, your first name, or your review history.
  • Your API keys are stored in the iOS Keychain and are only ever transmitted to the corresponding provider.
  • Submitted text is processed under the privacy policy of the provider you chose.
  • Advanced option: you can point the app at your own self-hosted AI server on your local network; in that case the text is sent to that server, which you own.

Speech recognition

For pronunciation exercises, Ikeru uses Apple's speech recognition. When your device supports on-device recognition, the app requires it and your audio never leaves your iPhone. If on-device recognition is not available, audio is processed by Apple's speech-recognition servers, as described in Apple's privacy policy.

Cloud backup (optional)

Ikeru offers an optional cloud backup of your learning data, off by default and enabled in Settings. It is hosted on Supabase, in the European Union region.

  • Account optional: when you turn this feature on, the app creates a random anonymous identifier by default, tied to this device, stored in the iOS Keychain. In that case there is no email, no login name, no password, and this identifier cannot be used to identify you personally.
  • Sign in with Apple (optional): you can choose to attach this anonymous identifier to your Apple ID via "Sign in with Apple", without losing anything already backed up. This creates an account, and Apple passes our authentication provider (Supabase) the email address associated with your Apple ID — potentially a private relay address if you chose to hide your email from Apple. Ikeru itself never reads, displays, or stores this address; it is kept by Supabase, tied to your account, alongside the rest of your data. The benefit: getting your progress back on another device by signing in with the same Apple ID.
  • What is sent: your learning progress, your cards and their memorisation state, your review history, the vocabulary you have recorded, your exercise results, the first name you entered in your profile, and your learning preferences (daily goals, target retention rate, and — if you have enabled them — the time of your review reminder and the day and time of your weekly check-in). If you sign in with Apple, the email address described above is added to this.
  • What is never sent: your conversations with Sakura (they stay on the device), the example sentences in which you encountered a word, your API keys, and your voice recordings.
  • Multi-device restore: without signing in with Apple, backup remains one-way per device — each device has its own anonymous identifier, so there is no automatic restore on a new device. If you sign in with Apple on multiple devices using the same Apple ID, those devices share the same account, and your progress can be retrieved and merged onto the new device.
  • Deletion: you can delete all of your data from the server at any time from Settings, which also erases the anonymous identifier and, if you signed in with Apple, the account and its associated Apple identity — nothing about you remains server-side afterward.

iCloud backup (not yet available)

This is a separate feature from the Supabase cloud backup described above. Ikeru includes the groundwork for a future optional iCloud backup feature, but it is disabled in the current build while the developer's Apple Developer account setup is finalized: there is no setting to enable it today, and no data is sent to iCloud. Once shipped, your learning data would be stored in the private CloudKit database of your personal iCloud account, encrypted in transit and at rest, but not end-to-end encrypted by default: Apple would hold the encryption keys, unless you have enabled Advanced Data Protection on your iCloud account. The developer of Ikeru would have no access to this data in any case. This section will be updated once the feature is active.

Third parties

Ikeru does not use any third-party tracking, analytics, or advertising service. Apart from the optional features described above, the only information Apple collects is described in Apple's privacy policy as part of TestFlight (crash reports, anonymous usage statistics for the developer).

Permissions requested

  • Notifications (optional): for the daily "Term of the Day" reminder, review reminders, and the weekly check-in
  • Microphone (optional): for pronunciation exercises
  • Speech recognition (optional): to transcribe your voice during pronunciation exercises

All permissions can be revoked at any time from iOS Settings.

Your rights

To erase all data stored locally by Ikeru: simply uninstall the app from your iPhone. If you have enabled cloud backup, you can delete all of your data from the server at any time from Settings, which also erases the anonymous identifier and, where applicable, the account and its associated Apple identity. For data portability, a local export is available in the app. For data sent to an AI provider you configured, please refer to that provider's privacy policy.
